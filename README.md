# Hasith Shavinda - Personal Portfolio Website

![Portfolio Banner](https://img.shields.io/badge/Portfolio-Live-brightgreen) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) ![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=flat&logo=tailwind-css&logoColor=white)

A modern, responsive, and interactive personal portfolio website showcasing my skills, projects, and experience as a web developer and programming student at Cardiff Metropolitan University. Built with cutting-edge web technologies and featuring a sleek dark theme with smooth animations and interactive elements.

## 🌟 Features

### 🎨 **Modern Design**
- **Dark Theme Interface** - Professional dark color scheme with purple accent colors
- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Smooth Animations** - CSS animations and GSAP powered interactions
- **Custom Cursor** - Interactive cursor effects for enhanced user experience
- **Gradient Text Effects** - Eye-catching gradient text styling

### 📱 **Interactive Components**
- **Typewriter Effect** - Dynamic text animation in hero section
- **Progress Bars** - Animated skill level indicators
- **Floating Elements** - Subtle floating animations for visual appeal
- **Hover Effects** - Interactive hover states throughout the site
- **Mobile Navigation** - Responsive mobile menu with smooth transitions

### 💼 **Content Sections**
- **Hero Section** - Personal introduction with animated profile image
- **About Me** - Educational background and personal information
- **Skills** - Technical skills with visual progress indicators
- **Projects** - Showcase of development projects with descriptions
- **Contact Form** - Functional contact form with Web3Forms integration
- **Customer Reviews** - Interactive review system with local storage
- **Social Links** - Links to LinkedIn, GitHub, Facebook, and Instagram

### ⚡ **Performance Features**
- **Optimized Loading** - Fast loading times with optimized assets
- **Intersection Observer** - Efficient scroll-based animations
- **Local Storage** - Client-side storage for reviews and preferences
- **CDN Resources** - External libraries loaded via CDN for better performance

## 🛠 Technologies Used

### **Frontend Technologies**
- **HTML5** - Semantic markup and structure
- **CSS3** - Custom styling with CSS Grid and Flexbox
- **JavaScript (ES6+)** - Interactive functionality and animations
- **Tailwind CSS** - Utility-first CSS framework for rapid styling

### **Libraries & Frameworks**
- **GSAP (GreenSock)** - Advanced animations and scroll triggers
- **Font Awesome** - Professional icon library
- **Animate.css** - CSS animation library
- **Google Fonts (Poppins)** - Modern typography

### **External Services**
- **Web3Forms** - Contact form submission handling
- **Intersection Observer API** - Efficient scroll-based animations

## 📱 How to View the Portfolio

### **Live Website**
Simply open the `index.html` file in any modern web browser to view the portfolio locally.

### **Local Development**
1. Clone the repository:
   ```bash
   git clone https://github.com/hasithshavinda918/Hasith-Shavinda-Portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Hasith-Shavinda-Portfolio
   ```

3. Open `index.html` in your preferred web browser:
   ```bash
   # On Windows
   start index.html
   
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   ```

### **Browser Compatibility**
- ✅ Chrome (recommended)
- ✅ Firefox
- ✅ Safari
- ✅ Edge
- ✅ Mobile browsers
